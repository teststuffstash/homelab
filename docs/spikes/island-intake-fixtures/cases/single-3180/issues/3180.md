## Deliverable

The gateway exports its store mode as a `gateway_db_mode` gauge family, and an alert fires while the deployed gateway runs on the fail-open `memory` store.

Why: a gateway that fell open to the in-memory store keeps admitting rides, but its sessions, caps, capacity marks and the codex rail's rotated credentials no longer survive a restart — and today only the start-up log line and `GET /healthz` say so. Filed by the 2026-11-06 janitor tick (sweep 5) from the two gap rows below; rewritten to the queue-ready shape by island intake (the original is in the edit history).

## Spec changes

Requirement: `GW-METRICS` on `gateway/specs/endpoints/metrics.md` — world `policy-default`; `store_state` as GW-HEALTH §Which store the gateway runs on defines it.

Family row (§The families — gauges and the histogram):

| family | type | labels | what it reads |
|---|---|---|---|
| `gateway_db_mode` | gauge | `mode` | 1 for the [store mode](../glossary.md#store-mode) the gateway opened at start (`pvc`, `memory`), 0 for the other — set once, for the process's life; `GatewayStoreMemoryMode` reads it |

Behaviour rows (a table of their own, "The store mode is a gauge"):

| description | store_state | pvc? | memory? |
|---|---|---|---|
| a mounted, writable PVC reads pvc | `file` | `1` | `0` |
| a fail-open store reads memory | `missing-dir` | `0` | `1` |
| both modes render on every gateway, the inactive one at 0 ⚖ | `file` | `1` | `0` (rendered, never absent) |

Bounded label (§Labels are bounded: credentials, the control plane, the catalog): `mode` takes `pvc` and `memory` only.

The alert ⚖ (prose in GW-METRICS beside the family, as the catalog legs state theirs; group `agent-gateway-db-mode`):

| description | series | fires? |
|---|---|---|
| the memory store pages after 5 minutes ⚖ | `gateway_db_mode{mode="memory"}` 1 | `GatewayStoreMemoryMode`, `severity: warning`, `triage: now` ⚖, after `for: 5m` |
| a PVC store is silent | `gateway_db_mode{mode="memory"}` 0 | none |
| an image older than the family is silent ⚖ | no `gateway_db_mode` series, `gateway_sessions_active` present | none (no `absent()` leg) |

Expr: `max(gateway_db_mode{job="agent-gateway",mode="memory"}) == 1`. The annotation names the start-up log line (`db: memory — FAIL-OPEN`), `GET /healthz`, and what is lost at the next restart.
