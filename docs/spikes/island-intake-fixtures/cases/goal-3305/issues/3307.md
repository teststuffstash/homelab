## Deliverable
The gateway derives the per-(rail, tier) model lists from its own store at each catalog refresh, keeps the last good derivation, and shows it on `GET /catalog/tiers` beside the list the admission walks — the admission itself is untouched.

Island: gateway. Second child of the runtime-tiers Goal (the shadow step). The operator's ruling (2026-11-12): "I am also leaning towards runtime. But with some monitoring, S3, grafana, etc. Can all be added later when it works already."

## Acceptance
1. `GW-MODEL-TIERS` on `gateway/specs/endpoints/catalog.md` gains the section and key rows below; the derivation is `agent_gateway.tiers`' own (`derive`, `join_aa_id`, `cost_per_clean_ride`, `undecided`, `unscored`) — no rule of it changes, and every existing GW-MODEL-TIERS row still passes.
2. A derivation runs after every good refresh of either catalog leg, from: the benched rows (`GET /catalog/openrouter` `benchmarks`, the first child), the Go price (`GET /catalog/opencode` `pricing`), the openrouter models' selected endpoints and rides, the manual benchmark rows when a file is mounted, and the policy's `tiers` block.
3. Candidates per rail ⚖: `opencode` and `openrouter` as GW-MODEL-TIERS §The rulings state them (from the two catalogs); `anthropic` and `codex` = the ids of the policy's `rails.<rail>.models` lists. No upstream read on a subscription credential is added.
4. `GET /catalog/tiers` answers a shape `catalog.schema.json` names: `derived_at`, the evidence stamps (the benched set's `as_of`, the two catalogs' `fetched_at`), and per rail and tier the derived list, each id's evidence row (score, price, basis, rides), `undecided`, `unscored`, and `equals_walked`.
5. The last good derivation is stored and survives a restart; a refresh whose derivation cannot run (no benched rows) keeps it.
6. The manual rows keep their rule: a row scores only an id the feed lacks, a row the feed carries is reported retired on the view; a malformed file refuses the whole file and the derivation runs without it ⚖.

#### The derivation at a refresh

| description | store_before | refresh | derived_at? | lists? | equals_walked? |
|---|---|---|---|---|---|
| a good refresh derives every rail's tiers ⚖ | catalogs and benched rows at T0, no derivation | openrouter leg ok at T0 + 21600 s | T0 + 21600 s | per rail and tier what `derive` returns over the store's evidence | per tier, true where the policy's list is the same ids in the same order |
