## Deliverable
The gateway keeps the latest answer of every vendor read it makes, per source, and serves it read-only at `GET /wire` (the index) and `GET /wire/<source>` (one member with its provenance).

Island: gateway. Child of Goal #3300 (the Goal's design pins bind this issue: the recorder sits before the parser; two source classes; latest answer only, in the gateway's own store).

## Acceptance
1. A new contract page `gateway/specs/endpoints/wire.md` (flow overview, requirement index, interface table) with `GW-WIRE-RECORD` and `GW-WIRE-VIEW`, its schema `wire.schema.json`, both rules in the `gateway/specs/README.md` index, and the terms `wire source` / `wire record` in `gateway/specs/glossary.md`.
2. Every vendor read the gateway already makes (the Go catalog's three reads, the OpenRouter catalog's reads, the codex usage poll) registers a source name and a class; the `GW-WIRE-RECORD` rows below pass, grown to the boundary rows the pinned process asks for.
3. `GET /wire` and `GET /wire/<source>` pass the `GW-WIRE-VIEW` rows; neither asks for nor returns a credential.
4. No existing row changes: the legs' parsers, snapshots and views read exactly what they read before.

## Spec changes
Requirement: `GW-WIRE-RECORD` on `specs/endpoints/wire.md` — world `policy-codex` (every world's gateway starts from the Go catalog's fakes; the codex usage fake answers the observed shape).

#### A read's answer is kept

| description | source | read | class | stored? | sha256? | fetched_at? |
|---|---|---|---|---|---|---|
| a public read's bytes are kept verbatim | go-models-dev | catalog-ok at T0 | public | the fake's bytes, byte-identical | the bytes' sha256 | T0 |
| a later answer replaces it | go-models-dev | catalog-trimmed at T0 + 21600 s | public | the later bytes | the later bytes' sha256 | T0 + 21600 s |
| a shape the parser refuses is still recorded ⚖ | go-models-dev | catalog-malformed at T0 | public | the malformed bytes | their sha256 | T0 |
| an account read keeps its structure and no string value ⚖ | codex-usage | the observed usage shape at T0 | account | every key, number and boolean; every string `{"len": n}` | the raw bytes' sha256 | T0 |

#### A failed read, a bound, a restart

| description | source | read | max_bytes | last_ok? | last_error? | complete? |
|---|---|---|---|---|---|---|
| a failed read keeps the last good answer and records the failure beside it ⚖ | go-models-dev | catalog-ok at T0, then catalog-503 | 1048576 | T0's bytes | status 503 at the later time | true |
| an unreachable vendor records no bytes | go-models-dev | catalog-down | 1048576 | none | `unreachable` | true |
| an answer over the bound is cut and says so ⚖ | go-models-dev | catalog-ok | 600 | the first 600 bytes | none | false |
| a record survives a restart | go-models-dev | catalog-ok at T0, restart at T0 + 3600 s | 1048576 | T0's bytes | none | true |

#### The credential never lands in a record

| description | source | read | record_bytes_with_key? | log_lines_with_key? |
|---|---|---|---|---|
| a vendor answer that echoes the key is withheld ⚖ | go-console-config | config-401-echo | 0 | 0 |
| a read that carried a credential is never class public | go-console-config | config-ok | 0 | 0 |

Requirement: `GW-WIRE-VIEW` on `specs/endpoints/wire.md` — world `policy-codex`.

#### The door

| description | recorded | request | status? | answer? |
|---|---|---|---|---|
| the index lists every source with its provenance and no body | go-models-dev at T0 | `GET /wire` | 200 | per source: class, url, status, bytes, sha256, fetched_at, age_s, complete |
| one member is its stored bytes, the provenance in headers ⚖ | go-models-dev at T0 | `GET /wire/go-models-dev` | 200 | body = the stored bytes; `x-wire-source`, `x-wire-class`, `x-wire-sha256`, `x-wire-fetched-at` |
