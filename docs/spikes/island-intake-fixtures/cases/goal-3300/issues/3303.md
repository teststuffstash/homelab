## Deliverable
`gateway/scripts/wire-quarry.py` — a stdlib tool that reads the gateway's wire door and prints a recorded answer with its provenance, finds which source has a shape, and cuts a fragment into a fixture file with a provenance sidecar; `gateway/specs/worlds/README.md` says where worlds come from.

Island: gateway. Child of Goal #3300; lands after the recorder child (native `blockedBy`).

## Acceptance
1. `GW-WIRE-QUARRY` exists on `gateway/specs/endpoints/wire.md` (section, index row, flow node) and in the `gateway/specs/README.md` index; the rows below pass against an in-process door, grown to the boundary rows the pinned process asks for.
2. The tool imports the standard library only and takes the door's base URL from the environment (default: the cluster Service name) — it holds and sends no credential.
3. `devbox run wire-quarry -- <verb>` exists in `gateway/devbox.json`.
4. `gateway/specs/worlds/README.md` gains §Where worlds come from: a fixture is cut from a recorded answer with `wire-quarry.py cut`, its sidecar is committed beside it, and a shape no source has recorded is not written.
5. `GW-WIRE-QUARRY`'s index row carries `⚑ gap`: the fixtures cut by hand before this tool have no sidecar, and nothing lints for one.

#### Reading the door

| description | door | command | exit? | stdout? | stderr? |
|---|---|---|---|---|---|
| `show` prints one member verbatim and one provenance line | go-models-dev at T0 | `show go-models-dev` | 0 | the stored bytes, byte-identical | `wire: source=go-models-dev class=public sha256=<…> fetched_at=T0` |
| `list` prints the index | go-models-dev at T0 | `list` | 0 | one line per source: name, class, status, age | — |
| `find` names the sources that have a key, with its path ⚖ | go-models-dev at T0 | `find --key cost` | 0 | `go-models-dev` and each JSON path ending in `cost` | — |
| a source nobody recorded is an error, never an empty answer | go-models-dev at T0 | `show codex-models` | 4 | nothing | `wire: codex-models not recorded` |
| a silent door is an error that names the door ⚖ | unreachable | `show go-models-dev` | 3 | nothing | `wire: door unreachable: <url>` |

#### Cutting a fixture

| description | door | command | exit? | fixture? | sidecar? |
|---|---|---|---|---|---|
| `cut` writes the fragment's values unchanged and a sidecar ⚖ | go-models-dev at T0 | `cut go-models-dev --path opencode-go.models.deepseek-v4-pro --out <dir>/m.json` | 0 | that subtree, values and key order as recorded | `<dir>/m.provenance.json`: source, class, url, sha256 of the whole answer, fetched_at, path |
