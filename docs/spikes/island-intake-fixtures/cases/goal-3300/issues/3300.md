## Goal

The gateway keeps what its vendors actually answered, and the loop can read it. Today every vendor answer is parsed into a normalised snapshot and the bytes are dropped; the fixtures under `gateway/tests/fixtures/` were cut by hand in jail sessions (worlds/README dates each one); and an endpoint the gateway does not call yet has no recorded answer at all — #3296 (`GW-CATALOG-CODEX`) is parked on exactly that: its rows cannot be written from a guessed `/models` shape, and a worker pod cannot read the account. The intent: a wire shape is **mined from a recorded answer, never hand-copied and never invented**, by a worker, a reviewer or a sitting, with no key in its pod.

**Acid test:** with the production leg done, a worker pod runs `gateway/scripts/wire-quarry.py show codex-models` and gets the enrolled account's `GET {CODEX_UPSTREAM}/models` answer with one provenance line (source, sha256, fetched_at, class); `wire-quarry.py cut codex-models …` writes #3296's fixture and its provenance sidecar; no jail session touches `gateway/tests/fixtures/`, and no credential or account identity is in either file.

Design pins the children elaborate:
- **The recorder sits before the parser.** Each vendor read the gateway makes keeps its latest answer per source in the gateway's own store (the precedent is GW-CODEX-CAPTURE's `captures` table) — a shape the parser refuses is the answer a worker most needs to see. Latest answer only; no history, no S3, no new credential.
- **Two classes of source ⚖.** `public` — the read sent no credential and no account header: the bytes are kept verbatim. `account` — anything else: sanitised structurally BEFORE persistence in GW-CODEX-CAPTURE's manner (structure, key names, numbers and booleans stay; every string becomes its length), except string values under keys the source's declaration allowlists, which are kept verbatim. An allowlist can never name an identity key, and GW-REDACT stays the second belt. (The alternative — verbatim minus a scrub of known identity values — is rejected here because an unseen payload can carry identity nobody listed.)
- **A read-only door, like `/catalog/*`:** `GET /wire` (the index, provenance only) and `GET /wire/<source>` (one member, provenance in headers). No credential in, none out ⚖.
- **A declared probe for an endpoint the gateway does not call yet:** a declaration names a source, a declared rail, a GET path on that rail's upstream and an interval; the read goes through the rail's own credential lifecycle. GET only, never an inference path, never a host the rail does not already reach.
- **The declarations are the operator's read ⚖ (operator, 2026-11-12: "4 my read").** Every probe declaration and every allowlisted key lives in ONE file of its own, never in the machine-merged `policy.json` and never in code: the gateway reads it from the path `GATEWAY_WIRE` names; no file, or an empty one, means no probe goes out and no account string is kept. The deployed file is **`argocd/resources/agent-gateway/wire.json`**, a codeowner path — the seat adds its `CODEOWNERS` entry by hand (`/argocd/resources/agent-gateway/wire.json`), and no child touches `CODEOWNERS`. The test worlds' declarations (`gateway/specs/worlds/wire-codex.json`) name fixture hosts and a fake upstream only.
- **The code ships before the declaration does:** nothing in this tree's children changes what the deployed gateway reads upstream; the deployed `wire.json` and its mount are the post-launch leg.
- **A stdlib tool is the loop's hand on the door:** `gateway/scripts/wire-quarry.py` `list | show | find | cut`. The door not answering is a non-zero exit that names it — never an empty or invented fixture.

## Acceptance

1. `gateway/specs/endpoints/wire.md` exists with `GW-WIRE-RECORD` and `GW-WIRE-VIEW`, their rows `rule()`-labelled and green; `GET /wire` and `GET /wire/<source>` answer the shapes `wire.schema.json` names (child 1).
2. `GW-WIRE-PROBE` and the account class's allowlist rows are green against the fake codex upstream; a gateway with no declarations file probes nothing and keeps no account string; a `wire` key in the policy refuses the load (child 2).
3. `gateway/scripts/wire-quarry.py` has its `GW-WIRE-QUARRY` rows green, and `gateway/specs/worlds/README.md` carries §Where worlds come from (child 3).
4. Post-launch, after the image carrying acceptance 1–2 is deployed and the `CODEOWNERS` entry for `argocd/resources/agent-gateway/wire.json` exists: that file declares the `codex-models` probe (`/models`, `client_version` ≥ 0.155.0) with an empty allowlist and the Deployment mounts it at `GATEWAY_WIRE`; a second change to the same file allowlists the keys the first record's structure shows to be model facts. Each change to that file is the codeowner's merge.
5. Production: `GET /wire` lists every source the gateway reads with an age under its interval, `GET /wire/codex-models` answers 200, and #3296 is re-ruled against it.
