Verdict: 14 rule files changed in 8 islands this week, a net gain of 52,193 bytes over 15 commits; 6 of those changes widen what a loop component may decide without the operator.

Terms used throughout (each defined in [`docs/glossary.md`](docs/glossary.md)):
- An **island intake sitting** is the scheduled session that takes an island's undecided issues and gives each exactly one outcome.
- **queue** means the issue is handed to a worker for one **ride**, a single worker run.
- A **Goal** is a funded multi-part issue tree. **goal** as an outcome means intake builds one.
- **seat** parks an item on the operator with `blocked-on: human`.
- An island's **facts file** is `docs/intake/<island>.md`: its membership, read set and operator-only lines, read in place of the gateway's own facts.

## What changed

### gateway

The main rules file of every island intake sitting is `gateway/intake.md`. It grew from 26.0 KB to 37.9 KB through ten commits.

**Review and repair before queueing; the escape read; spec-gap inputs.**
- An intake sitting that decides `queue` or `goal` now writes the issue bodies without labels first.
- Two independent review sessions then read those bodies, using the new lens briefs `gateway/intake-review-unit.md` and `gateway/intake-review-rows.md`. The sitting answers every finding once, posts one `intake: review` comment, and only then labels. The review never blocks the queue.
- The sitting also takes three new kinds of input:
  - **escape:** pull requests built from issues it queued that drew change requests. It classifies each finding using the new `gateway/intake-escape.md`. When the same class shows up twice, it files an issue against its own brief, a lens, or a facts file.
  - **gap:** the island's own flagged spec rows, which it may turn into issues.
- Paths the facts file adds to every issue no longer count toward the "about 5 paths" queue limit.
- Evidence: the commit cites the measured trial in `docs/spikes/island-intake.md` §Run 4 and its frozen cases.
- Class: **widens authority**, because the sitting may now file issues from spec rows and against its own rules, and the queue size limit is looser.
- Commit `c10ac8c`, #3378.

**Pull-request holds become re-read inputs.** When `INTAKE_PR_HOLDS=1` is set, the sitting is also offered issues whose open pull request carries `blocked-on: human`. It decides these in its report only and writes nothing to GitHub. The setting is off by default.
- Evidence: PR #3400 was parked on a human for a lock that a worker round could have fixed, and no sitting ever re-tested that wait.
- Class: **adds a read or tool**.
- Commit `9bb1f89`, #3421.

**Forward, and the commons.** The island a filer names on an issue is now treated as a hint, which step 0 tests on every issue.
- When another island wholly owns the issue, the sitting **forwards** it: it retitles the issue (bot-filed or operator-login, whatever its age) to that island's title prefix and adds one comment. It stops after 2 hops, or when the issue would go back to the island that sent it.
- A path that no island names is now "the commons": it goes with the island whose thing it serves, and is never parked on the operator just because nobody owns it.
- A split of a recent operator-login issue now leaves the original open.
- Evidence:
  - an operator ruling of 2026-11-15 on #3427, where `scripts/diff-ci.sh` had been parked because "no island owns it";
  - the first manual sitting on #3424, which could neither forward nor split.
- Class: **widens authority**.
- Commit `71b35c3`, #3428.

**Self-check of quoted rows (written by the loop).** Before copying an existing spec row into an issue body, the author now reads it as the rows reviewer would. Where the row's inputs do not decide its expected values, the body adds the missing column or clause.
- Evidence: no reason given. The pull request says it fixes #3495.
- Class: **adds a rule**.
- Commit `5a01b5e`, #3509, by the loop's GitHub App.

**Recurring responder findings become an input.** The sitting now gets one input per recurring class of report-only responder triages: same alert, same namespace, at least 3 in the lookback. A responder is the loop's alert-triage session. The sitting must decide on the class's cause, never by applying one instance's proposed fix.
- Evidence: six triages this week diagnosed the same pod-not-ready class on gateway rides, and nobody read the proposed fixes.
- Class: **adds a read or tool**.
- Commit `6c16647`, #3544.

**A ruling binds only the question it answered; undecided forks are intake's.**
- A recorded operator ruling now settles only the question it answered.
- An issue body under the operator's login counts as a ruling.
- Where no ruling decides a choice, the sitting picks the cheaper-to-reverse option itself instead of parking the item.
- Evidence: the first read of waits found 6 of 10 decidable from what intake already reads. The message says "operator-approved".
- Class: **widens authority**.
- Commit `9f264e8`, #3547.

**Step 3 becomes a closed list (ADR-164).** The sitting now parks an item on the operator only for one of six named entries:
- (a) access or money the island does not hold;
- (b) an attended or irreversible act, where a window on a surface the management box's capability ledger lists as `unattended` now queues instead;
- (c) direction;
- (d) another owner's gate;
- (e) a ruling recorded as pending on this exact question;
- (f) an issue it may not close.

With no entry, it decides and relies on alerts, the dig and the escape read to correct a wrong choice.

Other effects of the same commit:
- A fact outside the read set no longer parks the item. It is noted under `Unverified`.
- Waits on an issue or pull request now end when that item closes or merges.
- A re-read whose wait maps to no entry is decided again.
- For the gateway itself, a new public, credential-free upstream read on a vendor already read is now the island's to decide.
- Intake's own result is called an "outcome" throughout.
- The `operator, 2026-11-15` attribution on the commons rule was dropped from the brief. The rule itself stays.
- The same commit edits the facts files of agent-loop, launch, mgmt-box, retro, router-pair, scan and substrate, plus `docs/adr.md` and the intake skill.

Evidence: ADR-164, accepted by the operator on 2026-11-19, citing the same ten-wait read.
- Class: **widens authority**.
- Commit `1d3eca3`, #3549.

**The wait read.** The sitting gets a new `wait:` input: each past `blocked-on: human` parking comment, released or still standing. It classifies each one using the new `gateway/intake-wait.md`:
- H: truly the operator's fact;
- R: decidable from the read set;
- O: decidable only outside it;
- U: not judgeable yet.

When one rule line caused R or O waits on two distinct items, it writes a proposed rule edit as a receipt record. Nothing is filed or pushed. Waits whose named target has closed are re-read straight away.
- Evidence: no measured event cited; the message describes the mechanism ("the island's other improvement loop").
- Class: **adds a read or tool**.
- Commit `d9e4da9`, #3555.

### scan

This island and its facts file `docs/intake/scan.md` are new this week, and the same text was created for launch and retro.

**The starting contracts.** Three islands get facts files for components to be built fresh under `islands/`, with nothing live reading them yet. Each file sets:
- membership;
- a narrow read set;
- write tier `machine-merge` for `islands/**`, and nothing under `agents/**`;
- "switch-over is seat";
- an operator-only list.

At this commit `gateway/intake.md` marked them "facts only — not yet selector rows", and each file said any sitting on the island was the seat's, run by hand.
- Evidence: the message says they were carved from spike PR #3147 and reframed as starting contracts. No event or ruling is cited.
- Class: **adds a rule**.
- Commit `93330ef`, #3377.

**Specs reviewer on island roots.** Issue bodies on these islands must now expect a specs-reviewer pass over the island's specs. Every unproven row needs its WIP or gap mark. This replaces the earlier instruction to tell readers that no second approval exists.
- Evidence: #3379 put the three specs roots under the claim's `extraSpecs`.
- Class: **adds a rule**.
- Commit `d57766e`, #3402.

**Built from the specs, never copied.** Two things change:
- The "not yet selectable / sitting is the seat's by hand" hold is removed, so the scheduled sitting now decides these islands' issues. The selector rows themselves landed outside the rules set.
- The old code is no longer "the behaviour to match". Replay fixtures become a comparison, where every difference gets a ruling. A body asking a worker to match, port or carry over an old member is not queue-ready.
- Evidence: an operator ruling of 2026-11-15 that islands are rebuilt from their specifications, not ported.
- Class: **widens authority**, because the by-hand hold is gone. The copy ban itself narrows.
- Commit `04a7aeb`, #3435.

`1d3eca3` (gateway, above) changed one line here: a fact outside the read set goes under `Unverified` instead of parking the item.
