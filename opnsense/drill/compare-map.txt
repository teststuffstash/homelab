# The rebuild drill's comparison map (FU-297) — what a prod-vs-drill config.xml difference is
# ALLOWED to be. Read by opnsense/drill/config-compare.py; the method is in its header and in
# docs/opnsense-test-vm.md §The rebuild drill. Every difference NOT named here is bucket (a):
# on prod and not in code (or in code and not on prod) — the realism score counts those.
#
#   env       <kind> <path-glob>                  (b) environment-parametrized: the drill's own
#                                                     addresses, name, keys, WAN, seed
#   accepted  <kind> <path-glob>                  (c) certs, generated ids, timestamps, history —
#                                                     and what the drill deliberately cannot do
#   remap     <path-glob> <drill-prefix> <prod-prefix>   (b) a value that differs ONLY by the
#                                                     drill's LAN prefix (compared after rewrite)
#
# kind: * | value | prod-only | drill-only.  path: slash-separated tags, a list item as
# `tag[key]` (key = name/description/address/..., '/' in a key → %2F). Glob: `*` = within one
# path segment, `**` = across segments, everything else literal. First match wins.
# Keep it SMALL and SPECIFIC: a broad line hides the click-ops this exists to count. A line that
# matched nothing on a run is listed at the bottom of the drill report — delete it.
